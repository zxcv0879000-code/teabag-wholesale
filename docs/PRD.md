# 사이트 설계도(PRD) — (미정: 사이트 이름)

작성일: 2026-11-03 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
삼각티백을 2000개 단위로 거래처에 도매 납품하는 곳. 거래처는 받은 티백을 각자 포장해 소매로 판매한다.

## 2. 손님
- 누가: 온라인 쇼핑몰 셀러 (자기 포장으로 차를 파는 사장님)
- 어디서 알고 오나: 지인·거래처 소개 (소개받은 뒤 사이트 주소로 들어와 확인)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격 (개당·묶음당) — 사이트에는 공개하지 않고 문의 시 안내
2. 차 종류·품질
3. 샘플·서류 (샘플을 받아 볼 수 있는지, 판매에 필요한 식품 서류)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 제품·작업 사진 (사진은 사용자가 준비해서 넣는다)
- 식품 관련 서류 (어떤 서류인지: 미정)
- 거래 경력·거래처 (기간·거래처 이름: 미정 — 사용자가 알려 준 사실만 적는다)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 도매 단가 문의
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + [도매 단가 문의] 버튼
2. 이렇게 거래해요 — 2000개 단위 납품 → 거래처가 직접 포장해 소매 판매
3. 차 종류 (목록: 미정)
4. 믿을 수 있는 이유 — 제품·작업 사진, 식품 서류, 거래 경력(사실만)
5. 자주 묻는 것 — 가격(문의 시 안내), 샘플, 서류
6. 후기 자리 (비워 둠)
7. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 원하는 차 종류
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 비공개 (문의 시 안내)
- 납품 단위: 2000개
- 차 종류: (미정)
- 경력·거래처: (미정)
- 샘플 가능 여부: (미정)
- 위치: (미정)
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 결제 (온라인 주문·결제)
- 사진 올리기 (손님이 파일 첨부)
- 알림 메일
- 블로그·소식 게시판

## 10. 첫 화면 한 문장 후보
1. 쇼핑몰 셀러를 위한 삼각티백, 2000개 단위로 납품합니다.
2. 내 브랜드 포장으로 파는 차, 티백은 저희가 준비합니다.
3. 직접 포장해 판매하실 삼각티백, 도매 단가부터 물어보세요.

## 11. 다음에 할 것
- 사이트 이름 정하기
- 차 종류 목록, 경력·거래처, 식품 서류 이름, 샘플 가능 여부, 연락 방법 채우기
- 제품·작업 사진 준비
- 회원 전용 페이지에 무엇을 보여 줄지 정하기 (미정)
- 개인정보 처리방침 페이지 준비 (회원가입이 있으므로 필수)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 필요 → Supabase Auth로 회원가입·로그인·회원 전용 페이지, /admin에 회원 목록. 개인정보 처리방침 페이지를 함께 만든다.
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 회원가입·로그인 → 회원 전용 페이지 → 개인정보 처리방침 → /admin 회원 목록을 붙인다
5. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
